Feedback workbook structure
- Add one new row for each new participant submission.
- Participant Name, Submission File, and Milestone identify the submission.
- Each criterion has its own score column.
- Area of Strength, Area for Improvement, and Overall Feedback are the three feedback columns.
- Total Score calculates when all five criterion scores are numeric.
- This is a blank/template register; it does not populate itself from GitHub Actions unless the evaluator/report-generation code is configured to append rows to this workbook.
